# Security

TOSS Terminal runs shells and reads and writes files, so security bugs matter.

## Reporting

Please report privately through GitHub: on
[LunarLogician007/toss-terminal](https://github.com/LunarLogician007/toss-terminal),
open **Security → Report a vulnerability**. Include what the issue lets an
attacker do, steps to reproduce, and your version and macOS version.

Please don't open a public issue for security reports.
